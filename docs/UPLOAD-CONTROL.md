# کنترل ارسال فایل (ادمین)

پنل ادمین ← تب «ارسال فایل». برای هر دسته: **همه** | **هیچ‌کس** | **فقط کاربران خاص** (نام کاربری‌ها با ویرگول).
دسته‌ها: تصویر، ویدیو، پیام صوتی، موزیک، فایل و سایر.

- اعمال در سرور است: Caddy مسیرهای آپلود `/_matrix/media/*/upload|create` را به gateway می‌دهد؛ gateway توکن و سیاست را بررسی می‌کند و بعد به Synapse پراکسی می‌کند. (کتابخانهٔ موزیک `/api/music/tracks` هم همین سیاست «موزیک» را دارد.)
- دستهٔ هر آپلود از Content-Type می‌آید؛ برای فایل‌های رمزشده برنامه `application/octet-stream; tk=<دسته>` می‌فرستد.
- فایل‌های کوچک‌تر از «حد فایل کوچک» (پیش‌فرض ۵۱۲KB) همیشه مجازند، چون عکس پروفایل، کاور، بندانگشتی و استیکر لازم دارد. با ۰ این استثنا حذف می‌شود.
- برنامهٔ کاربر سیاست خودش را از `/api/uploads/policy` می‌گیرد و دکمه‌های بسته‌شده را خاموش می‌کند.
- محدودیت: این کنترل برای **صرفه‌جویی مصرف** است نه امنیت؛ کلاینت دستکاری‌شده می‌تواند دستهٔ دروغ اعلام کند. برای سقف واقعی حجم از سهمیهٔ کاربر (`QUOTA`) استفاده کن.
- روی سرور جدید یا بعد از آپدیت، Caddyfile باید به‌روز باشد (آپدیت اسکریپت خودش آن را می‌گذارد).
