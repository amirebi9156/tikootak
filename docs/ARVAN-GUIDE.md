# راهنمای راه‌اندازی روی ابر آروان (tikootak.ir)

> نام دقیق منوها در پنل آروان ممکن است کمی فرق کند؛ منظور همان بخش‌هاست.

## ۱. ساخت سرور
- نوع: سرور ابری (IaaS)، سیستم‌عامل **Ubuntu 22.04 یا 24.04**، حداقل **۲ هسته / ۴ گیگ رم / ۸۰ گیگ SSD**.
- حتماً **IPv4 عمومی** بگیر و **کلید SSH** خودت را اضافه کن (به‌جای رمز).
- در بخش **فایروال / گروه امنیتی (Security Group)** سرور، این‌ها را باز کن (ورودی، از همه‌جا):
  `22/tcp  80/tcp  443/tcp  7881/tcp  7882/udp  3478/udp  30000-30100/udp`
  (UDPها برای تماس صوتی/تصویری لازم‌اند؛ اگر پنل UDP را نمی‌پذیرد، به پشتیبانی بگو.)

## ۲. DNS (دامنه‌ای که NS آن آروان است)
در پنل آروان ← دامنه ← **DNS**:
- رکورد **A** برای `@` (یا `tikootak.ir`) با مقدار IP سرور.
- حتماً **ابر را خاکستری کن (DNS only)**. اگر ابر نارنجی (CDN/پروکسی) باشد، تماس‌های UDP کار نمی‌کنند و گواهی HTTPS گرفته نمی‌شود.
- TTL را روی ۳۰۰ ثانیه بگذار (برای جابه‌جایی سریع‌تر در آینده).
- تست: `nslookup tikootak.ir` باید IP سرور را بدهد.

## ۳. آپلود پروژه و نصب
```
scp tikootak-UI32.tar.gz root@IP_SERVER:~/
ssh root@IP_SERVER
tar xzf tikootak-UI32.tar.gz && cd tikootak
sudo ./scripts/bootstrap.sh --domain tikootak.ir
```
اگر Docker Hub/npm باز نبود، اسکریپت خودش می‌گوید؛ راه‌حل‌ها:
- `--mirror https://docker.arvancloud.ir` (آینهٔ آروان؛ آدرس را قبل از استفاده در مستندات آروان تأیید کن)
- یا روی کامپیوتر خودت (اینترنت آزاد) `./scripts/pack-offline.sh` و فایل `offline-images.tar.gz` را کنار پروژهٔ سرور بگذار.

## ۴. بعد از نصب
- `https://tikootak.ir` را باز کن؛ با کد دعوتی که چاپ شد ثبت‌نام کن.
- کلید ادمین و **کلید رمز بکاپ** را جای امن (بیرون از سرور) ذخیره کن.
- `sudo ./scripts/security-test.sh --app` و بعد چک‌لیست `docs/TESTING.md` (تماس را حتماً از دو شبکهٔ مختلف امتحان کن).
- وقتی همه‌چیز درست بود: `./scripts/admin.sh signup status` و ثبت‌نام را فقط با کد دعوت نگه دار.
